🎤 Judge Q&A Defense Strategy

"Why use CDP instead of standard Selenium?"
Selenium launches isolated automation binaries that expose navigator.webdriver = true, which modern proctors block instantly. CDP attaches directly to an already running, authenticated user session with zero bot fingerprints.
"How does it handle changing HTML structures?"
It uses an Autonomous Screen-Perception Engine that scans visible elements and tags them with dynamic targets. The LLM visualizes the interface semantically rather than relying on brittle CSS class names.
"Why doesn't the agent submit the exam automatically?"
The agent incorporates a Human-in-the-Loop Safety Shield. It audits and solves all questions, but preserves the final submit button so human proctors can review answers and retain absolute execution control.
